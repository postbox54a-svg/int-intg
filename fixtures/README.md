# Fixtures

One sample response per source, in the source's own format. Tests parse these files. When a source's domain is
blocked, point the worker's URL env var at a fixture with a `file://` URL.

| File | Source | Real or synthetic |
| --- | --- | --- |
| `usgs-quakes.synthetic.geojson` | USGS summary GeoJSON feed | **Synthetic.** It follows the USGS schema, but the events are invented, because earthquake.usgs.gov was blocked in the cloud session. It has 12 events inside INDIA_BBOX and 3 outside it (Japan, Chile, Iran). Replace it with a saved real `2.5_week.geojson` once the domain is reachable. |
| `adsblol-flights.synthetic.json` | adsb.lol `/v2/point` (ADSBExchange v2 format) | **Synthetic.** 64 invented aircraft. 58 are civil aircraft over India; 6 must be filtered: no callsign, blank callsign, `dbFlags` military, US military hex block, outside INDIA_BBOX, and one malformed entry. api.adsb.lol is blocked in the cloud. |
| `opensky-states.synthetic.json` | OpenSky `/api/states/all` | **Synthetic.** 13 state vectors (the first 10 adsb.lol aircraft converted to OpenSky units), plus a military hex, a blank callsign and one outside INDIA_BBOX. opensky-network.org is blocked in the cloud. |
| `sachet/rss.xml` + `sachet/cap-*.xml` | SACHET RSS feed with linked CAP 1.2 alerts | **Synthetic.** 9 invented alerts, one per case: a CAP polygon with English and Hindi info blocks, district-only areas, a district name shared by two states (Bilaspur) resolved through the headline, a CAP circle, a post-2011 district (unmatched), an expired alert, an Update that supersedes an older alert, and an Exercise. Expiry dates are in 2027 so the e2e run shows them. sachet.ndma.gov.in is blocked in the cloud. |
| `news/gdelt-artlist.synthetic.json`, `news/rss.synthetic.xml`, `news/atom.synthetic.xml` | GDELT DOC 2.0 artlist, RSS 2.0, Atom | **Synthetic.** 22 invented headlines with `.invalid` URLs dated 3 Oct 2026. They include an exact duplicate (same URL with `utm_`), a near-duplicate title, two with no place, one older than 6 h, one placed only by its summary, and an old city name (Bombay). Tests pin the clock; to run them live, shift the dates to now. GDELT and the news sites are blocked in the cloud. |
| `gazetteer-in.sample.json` | GeoNames-style gazetteer rows | **Hand-made sample, not GeoNames.** 56 large Indian cities with approximate coordinates, rounded populations and common old names. Used only until `apps/ingest/data/gazetteer-in.json` is built from GeoNames `IN.txt` (`pnpm --filter @ind-intg/ingest build:gazetteer IN.txt`). download.geonames.org is blocked in the cloud. |
| `aisstream-messages.synthetic.jsonl` | AISStream WebSocket messages, one JSON per line | **Synthetic.** 42 invented vessels anchored or under way off JNPT, Mundra, Chennai, Visakhapatnam, Kochi and Kolkata, most with ShipStaticData. Also a Class B yacht off Goa, a type-35 vessel (position first, then static, so it must be removed), one outside INDIA_BBOX, an AtoN message and one malformed message. stream.aisstream.io is blocked in the cloud and there is no key. |
